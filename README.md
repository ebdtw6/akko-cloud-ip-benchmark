## 这三个测试入口具体怎么用

Looking Glass 页面点开后就有 ping、traceroute、speedtest 三个按钮，在浏览器里直接运行，不需要自己在本地安装工具。伦敦机房还单独放了一个 1000MB 测试文件，地址是 lonlg.akkocloud.com/1000MB.test，用下载器拉一遍，能看出实际吞吐与公告带宽相差多少。

本地需要做两件事。第一，对每个测试 IP 持续 ping 两三分钟，观察平均延迟和抖动，而不是只看第一次返回的数字。第二，Windows 用 `tracert`、Mac 和 Linux 用 `traceroute`，观察数据包从你所在省份的出口出去后，落在哪个网段。

AkkoCloud 是 2019 年开始运营的国人商家，走二次元风格，三个机房全部采用 KVM 架构，宣传口径都是三网回程 CN2 GIA，付款方式只支持支付宝这一种。这些属于基本背景信息，真正影响你下单的，是下面几件更具体的事。

## 测出来的数字怎么读

延迟数值本身说明不了太多问题，同样是 180ms，一条稳定不丢包的线路和一条每分钟断一次流的线路，体验相差极大。

回程判断看 `59.43`。这个网段属于电信 CN2 骨干，回程路由里出现它，说明流量走的是 CN2。2026 年 4 月的一份第三方测评在伦敦机房做过完整路由追踪，电信去程依次经过 `59.43.46.77`、`59.43.159.18`、`59.43.39.118`，再经法兰克福落地伦敦；联通去程走的是 `162.255.48.x` 的 AS10099；移动去程走 CMIN2 的 `223.120.x.x`。

这和“三网全 GIA”的宣传有出入：去程只有电信确实走 CN2，联通和移动各走各的精品网。三网都能直连回国，但三者并不属于同一种线路。

带宽方面有一个容易被忽略的细节：官方测速文件和你实际买到的那台机器，走的是不同 IP、不同路由。官方自己在套餐页底部写明了“测试 IP 只是测试参考，并不代表分配的 IP 就是这个段的，也不保证是原生 IP”。所以测速能帮你筛掉明显不合适的机房，无法保证到手机器和 Looking Glass 表现一致。有人 ping 测试 IP 很快，收货后发现延迟多了 20ms，这种情况不罕见，购买前需要接受这个概率。

## 三个机房的实测数字

下面是第三方测评者跑出来的结果，并非官方 SLA，也不是我本人的测试。

**圣何塞**：国内 ping 大致 150ms 到 168ms。一份测评写本地 ping 约 150ms，另一份写平均 168ms，差异来自测试点不同。电信联通去程走 CN2 GIA，移动去程直连，官方称三网回程强制 GIA。在美西 CN2 GIA 这个档位里属于正常水平。

**法兰克福**：延迟 177ms 到 180ms 上下。有一份搜索摘要提到 177ms，另一篇测评写 180ms，量级一致。一个做定期复测的测评站记录过，2024 年 10 月法兰克福的移动线路上传只有 19Mbps，怀疑被 QoS；到 2026 年 9 月的定期更新又恢复平稳。欧洲线路受运营商策略调整影响，这种波动会反复出现。

**伦敦**：2026 年 4 月的一份第三方测评给出的 ping 集中在 171ms 到 194ms，看着不错。同一份测评的 iperf3 结果带来了另一个问题。

评测者原话是“这个机器有点拉跨啊，这真是 CN2GIA 吗”。他先怀疑对端机器故障，换荷兰和美西的其他线路机复测，三网都正常、没有断流，才判断问题在 AkkoCloud 这台机器本身。iperf3 输出里有连续两段 `0.00 Bytes 0.00 bits/sec` 的完全停滞，各持续一到两秒，单线程速率掉到 3.73 到 28.1 Mbits/sec，正常时段能跑到 104 到 139 Mbits/sec。三组丢包测试分别是 660 包 0%、661 包 1.36%、909 包 3.52%。

这是单台机器、单次测试的结果，不能据此断定整个伦敦机房都这样。但它至少说明一件事：伦敦机房的“三网回程 CN2 GIA”宣传，和某台具体机器的实际表现之间可能有很大距离。买伦敦款之前，晚高峰多 ping 几轮，比看任何测评都直接。

顺带说一句时效。网上流传的伦敦流媒体解锁表来自 2022 年 5 月的测试，当时 Netflix、BBC iPLAYER、ITV Hub 都能解锁。四年过去，IP 段和解锁状态几乎肯定已经变化，拿那份表当购买依据没有意义。同一批 2022 年数据里还有 I/O 645.7MB/s、UnixBench 单核 649.3 分，只能当老机型的性能参考。

## 买完发现不对，工单需要什么证据

这条在别处很少被提到，但它直接影响你能不能维权。

官方的工单规则是：网络故障必须提供 ipip.net 截图、mtr 截图或 traceroute 截图；速率问题必须提供 iperf3 测试截图。缺了这些，技术团队保留拒绝答复的权利。

所以测速这套动作不只是买前用。买之后发现掉速、断流，你得拿得出同一套数据：本地到机房的 mtr、机房侧的 iperf3 结果、ipip.net 的线路归属截图。只会说“很慢”的工单，大概率被要求补材料再排一次队。

工单回复速度方面，第三方文章转述的用户反馈是基本 24 小时内会有回应，这属于用户观察，不是官方承诺。

## 几个常被问到的问题

**测试 IP 延迟高，是不是这家不行？**

大概率是你本地出口的问题。同一个机房，电信、联通、移动走的路由完全不同，不同省份也不一样。换几个时段各测一轮，看平均值和抖动，比单次结果可靠。

**Looking Glass 的回程和我到手的不一样？**

正常。LG 跑的是机房那台测试机，你买到的是另一个 IP 段。官方对此有明确免责，测试 IP 不代表分配 IP 的段，也不保证原生 IP。有原生 IP 硬需求的话，别把 LG 结果当承诺。

**三个机房怎么选？**

要国内访问速度，优先测圣何塞，延迟最低。需要欧洲 IP 或对接欧洲业务，看法兰克福。要英国 IP，看伦敦，但先接受它可能断流这件事。三机房都是 KVM，都标三网回程 GIA，差别主要在地理位置和你那条宽带的路由。

**支持什么付款方式？**

只有支付宝。没有 PayPal，也没有信用卡通道，习惯用外卡的话这一步就卡住了。

**有没有优惠码？**

目前没有可确认有效的具体优惠码。特惠款本身已经是折扣价，通常不需要额外码。第三方流传的码可以到结算页试一下是否生效，别指望能叠加。
